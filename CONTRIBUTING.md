# Contributing to Wolium

Thank you for your interest in improving Wolium.

Wolium is proprietary software, but community contributions such as
bug fixes and improvements are welcome.

---

## Allowed Contributions

You may fork this repository for the purpose of:

- reviewing the source code
- reporting bugs
- submitting bug fixes
- improving translations
- suggesting improvements via pull requests

---

## Restrictions

Forking the repository does **NOT** grant permission to:

- reuse Wolium code in other projects
- deploy modified versions of the bot
- redistribute Wolium software
- build competing or similar services

All Wolium code remains proprietary.

---

## Pull Requests

When submitting a pull request:

- keep changes focused
- describe what problem the change solves
- avoid unrelated modifications

The project owner reserves the right to accept or reject contributions.

---

## Reporting Bugs

If you find a bug, you can:

- open a GitHub issue
- report it in the support server

Discord Support Server:  
https://discord.gg/MXupeAApza

---

## Security Issues

If you discover a security vulnerability, please report it privately.
