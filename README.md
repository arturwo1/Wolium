# Wolium™ — Global Economy, Moderation & Activity Discord Bot

**Wolium** is a multi-system Discord bot focused on **global progression**, **server activity**, and **practical moderation tools**.

It combines economy, activity tracking, optional AI features, and moderation into one stable system without unnecessary complexity.

---

## Core Concept

Wolium is designed to:

- Increase server activity naturally  
- Provide long-term user progression  
- Reduce moderator workload  
- Keep systems simple but powerful  
- Give users control over optional data logging and AI features  

---

## Features

---

### 💰 Global Economy (Cross-Server)

All users have a **single global profile** across every server where Wolium is installed.

**Includes:**
- Shared balance, bank, and XP  
- Automatic rewards for:
  - chat activity  
  - voice activity  
- Global leaderboards  
- Profile cards with detailed statistics  

**Key Idea:**  
Progression is persistent. No server resets. No fragmentation.

---

### 🛡️ Moderation

Core moderation tools designed for speed and clarity.

**Includes:**
- Ban / Unban  
- Kick  
- Timeout / Mute  
- Bulk message deletion  
- User and message reporting  
- Action logging (audit visibility)  

---

### 📊 Activity Tracking

Optional activity tracking systems:

- Chat activity XP  
- Voice activity tracking (join time, channel transitions)  
- Participation-based rewards  

---

### 🌍 Language & Translation

- Per-user language selection  
- Automatic response localization  
- On-demand translation tools  

---

### 🤖 AI Chat Assistant

Mention Wolium to:

- Ask questions  
- Get explanations  
- Check rules  
- Clarify meanings  

⚠ AI responses may be inaccurate. Always verify important information.

---

## Privacy & Data Control

Wolium is designed with **user-controlled data collection**.

**Important Notes:**

- Full message logging is **opt-in only** (or enabled when explicitly requested by the user)  
- Users can delete all stored data via bot command  
- OAuth tokens are encrypted  
- Data is stored in EU infrastructure  
- No user data is sold
